# 电子抄表本 · ZSLR

面向逐户水表录入的本地工具。导入 Excel 后选择工作表和月份，记录读数、换表或拆表情况，完成核对后生成本期结果。表格和录入数据均在浏览器本机处理，无后端、无数据上传。

## 本地运行

需要 Node.js 22.12+ 和 pnpm。

```sh
pnpm install
pnpm dev --port 5185 --strictPort
```

打开 `http://127.0.0.1:5185/`。保持使用同一浏览器、地址和端口，自动保存的抄表本按浏览器来源隔离。

```sh
pnpm test
pnpm build
pnpm preview --port 5185 --strictPort
```

`dist/` 可交给普通静态服务器。正式使用请用 HTTPS 或本机 localhost。`index.html`、`指数录入.html` 和 `指数录入v0.91.html` 都使用同一套新代码；旧版本可从 Git 历史查阅。

## 手机与离线

离线资源缓存仅在生产构建中启用，开发服务器不提供离线保证。首次联网打开生产版，等待侧栏显示「离线资源已就绪」后，可断网重开并继续录入、备份和导出。支持安装提示的浏览器显示「安装抄表本」；iPhone 可通过 Safari 的添加到主屏幕安装。

手机访问需要部署到 HTTPS 地址。电脑的 `127.0.0.1` 不能从手机直接访问，普通局域网 HTTP 也不满足 Service Worker 的安全上下文要求。安装状态与离线资源就绪状态分开处理。

新版本不会强制刷新正在录入的窗口；显示「新版待启用」后，完成本机保存并关闭该应用的全部窗口，再打开启用新版。升级只替换程序资源，不清理 IndexedDB 抄表数据。浏览器主动清理、设备损坏或用户删除站点数据仍可能造成数据丢失，必须保留文件备份。

## 异常与收工交接

暂缓原因包含无法入户、表盘不清、水表故障、未找到水表、其他原因；其他原因必须填写备注。「暂缓」筛选用于待回访户，「异常」筛选同时列出暂缓、换表、拆表和异常用量户。录入错误会滚动到错误提示。

「收工交接」生成一个 `.zslr.zip`，可直接通过「恢复备份」导入，包含原始文件、完整进度及 Excel 清单。清单分为交接明细、未完成清单、异常复核清单，按原工作表行号区分同号水表。未录与暂缓读数留空，未确认草稿单独列出；不会按零读数上账。

全部记录确认后，交接包另含正式结果工作簿；未完成时文件名和说明标注「未完成」，不含正式结果。最近备份与交接时间表示本机生成时间，不代表下载文件已落盘或已被他人签收。收工时需要确认设备中确实存在 ZIP 文件。

本版不包含照片采集、云端同步或营销系统自动上账。换表用量仍需业务核算。

## 表格约定

- 支持 `.xlsx`，最大 20 MB；`.xls` 请先在 Excel 中另存为 `.xlsx`。
- 前 20 行中应有包含「抄表号」「指数」的表头，每个表头名称唯一。
- 抄表号和上期指数为必填。计费号、用户名称、水表地址、备注信息可留空。
- 「录入月份」和历史指数列用 `YYYY-MM`。本期月份必须晚于已有录入月份；同一期的纠错在已保存抄表本中完成。
- 重复抄表号可导入，会显示重号标记。记录按工作表名称和原始 Excel 行号区分。
- 读数为非负数，最多 3 位小数。正常抄表不能倒退；换表需填写原因，换表用量不自动按差值计算。
- 公式指数使用文件内已保存的计算结果。工具不运行 Excel 公式；导入前请在 Excel 中完成重算并保存。

## 保存、纠错与导出

录入草稿、已确认读数、暂缓原因、当前户和修改记录自动保存到 IndexedDB。「已保存到本机」表示写入事务完成；失败时保留当前页面中的数据并提示备份。多页面修改采用版本检查，旧页面无法覆盖新记录。

点击任意用户可回看和纠错。已确认修改记录保留前后读数和时间。未录、暂缓、未确认修改都会阻止正式导出；未完成时可下载 `.zslr.zip` 进度备份。备份包含原始工作簿、草稿、记录和修改历史，恢复后生成独立抄表本，不覆盖已有进度。

清理浏览器数据、使用无痕窗口或更换电脑会影响本机存储。自动保存不能替代文件备份，完成一轮现场工作后请下载备份。

正式导出从原始工作簿副本生成，更新所选工作表的指数、录入月份、历史指数和备注，不修改导入文件或录入状态。其他工作表及未涉及的 ZIP 部件保留原始字节；计算链会被移除并标记由 Excel 打开时重新计算。同一进度重复导出的内容一致。

当前每个抄表本编辑一个工作表。多个工作表分别录入时，需要按顺序将已导出的工作簿作为下一张工作表的输入，以保留前一张表的结果。

## 实现与验证

- `src/book.js`：模板校验、逐行身份、读数确认、进度备份与原文件导出。
- `src/storage.js`：原文件和进度的事务保存、版本冲突检测。
- `src/App.vue`：逐户录入、搜索筛选、回看纠错和响应式界面。
- `src/pwa.js`、`vite.config.js`：安装提示、离线缓存和非强制更新。
- `tests/`：数据完整性、Excel 往返、备份恢复和存储失败回归测试。

Excel 解析使用 [SheetJS 官方发行包](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/)。原始 `.xlsx` 使用 fflate 解包，仅修改指定 XML 单元格，避免重建工作簿时丢弃其他工作表和格式。
